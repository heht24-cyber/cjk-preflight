# 真实示例集

以下全部是本仓库开发与压测过程中遇到的真实输出（非摆拍）。
文件路径为开发机上的原始路径，输出逐字保留。

## 例 1 · 中文学位论文模板指南（四种问题一网打尽）

上海大学 shtthesis 模板的官方使用指南，46 页，XeLaTeX 编译：

```
$ cjk-preflight check shtthesis-user-guide.pdf

shtthesis-user-guide.pdf  (46 页)
  [ERROR] p31 notdef: □ U+25A1（豆腐块） ×1  …⊢(𝑃⥽𝑄) ⥽(□𝑃⥽◇𝑄)…
  [WARN ] p0 metadata: 作者字段非空: 李润东  …提交评审版建议清空或匿名
  [WARN ] p20 kinsoku: 行首出现避头标点『）』  …），也不推荐在overleaf 等在线平台编译使…
  [HINT ] p1 mixed-width: 中英文之间无空格『年3』  …技术学院 2022 年3 月
  —— 1 error / 2 warn+hint
```

看点：官方模板自己的指南也有豆腐块（模态逻辑符号 □ 缺字形）、
作者真名留在元数据里、行首避头标点。

## 例 2 · Word 转 PDF 课件（字体未嵌入重灾区）

传热学课程整合资料，30 页，Word/WPS 转出：

```
$ cjk-preflight check 传热学整合版.pdf --checks fonts,kinsoku

传热学整合版.pdf  (30 页)
  [ERROR] p0 font-not-embedded: 字体未嵌入: /ABCDEE+宋体
  [ERROR] p0 font-not-embedded: 字体未嵌入: /ABCDEE+微软雅黑
  [ERROR] p0 font-not-embedded: 字体未嵌入: /Times New Roman,Bold
  [ERROR] p0 font-not-embedded: 字体未嵌入: /Times New Roman
  [ERROR] p0 font-not-embedded: 字体未嵌入: /Symbol
  [ERROR] p0 font-not-embedded: 字体未嵌入: /Times New Roman,Italic
  [ERROR] p0 font-not-embedded: 字体未嵌入: /Arial,Bold
  [ERROR] p0 font-not-embedded: 字体未嵌入: /Arial
  [WARN ] p10 kinsoku: 行首出现避头标点『·』  …·导热微分方程在一个具体问题中的变形和化简。
  —— 8 error / 30+ warn
```

看点：8 个字体全部未嵌入——Word 转 PDF 的典型病。这台电脑上能看，
换一台没装这些字体的机器（打印店、评审系统）就会缺字或替换。

## 例 3 · 泰文 LaTeX 教材（CJK 近亲，证明通用性）

TeX Live 自带的泰文版《The Not So Short Introduction to LaTeX》，74 页：

```
$ cjk-preflight check lsh132.pdf --checks notdef

lsh132.pdf  (74 页)
  [ERROR] p53 notdef: □ U+25A1（豆腐块） ×1  …ℏ \hslash k \Bbbk □ \square ■ \blacksquare…
  —— 1 error / 0 warn+hint
```

看点：数学符号表里的 \square 在泰文字体环境没有字形，渲染成豆腐块。
非中文的 CJK/复杂文字场景同样适用。

## 例 4 · 自己的 XeLaTeX 作业（干净基准，验证不误报）

中文 LaTeX 作业（xeCJK + ctex 排版），2 页：

```
$ cjk-preflight check 作业9.pdf

作业9.pdf  (2 页)
  [HINT ] p1 mixed-width: 中英文之间无空格『为x1』  …静平衡位置向下的位移为x1, x2, x3。图…
  [HINT ] p1 mixed-width: 中英文之间无空格『则K』  …1, 1, 1]T，则K = k(4I −eeT…
  —— 0 error / 23 warn+hint   （exit code 0）
```

看点：字体全嵌入、禁则零违规（LaTeX 引擎自动处理悬挂标点）。
mixed-width 的 hint 属于风格建议（数学变量紧贴中文在理科文档很常见），
error 级为零——工具不冤枉排版良好的文档。

## 例 5 · 工程图纸（纯图形 PDF，安静通过）

PCB 加工图草稿，1 页，无文本层：

```
$ cjk-preflight check 加工图草稿.pdf

```

看点：纯图形 PDF 没有文本可查，工具安静通过而不是报一堆假问题。
